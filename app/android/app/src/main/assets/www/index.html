NUBE 1/5 · GITHUB

Tu cuenta de GitHub

GitHub ejecuta mi cerebro cada 30 min, gratis, en un repositorio privado tuyo, y guarda tus claves cifradas.
  1. Crea una cuenta gratis en GitHub si no tienes.
  2. Toca CREAR TOKEN: ya vienen marcados repo y workflow. Elige una caducidad y pulsa «Generate token».
  3. Copia el token (empieza por ghp_) y pégalo aquí.
NUBE 2/5 · CLOUDFLARE

Tu cuenta de Cloudflare

Aquí vive tu nube: guarda la configuración y responde a esta app. El plan gratis alcanza de sobra.
  1. Crea una cuenta gratis en Cloudflare.
  2. Abre API TOKENS → Create Token → plantilla «Edit Cloudflare Workers» → en Account Resources elige tu cuenta → Create Token.
  3. Copia el token y pégalo aquí. La cuenta la detecto yo.

Tu IA
